# 이력

무엇을 **언제** 했는지. 왜 그렇게 했는지는 [HANDOFF.md](HANDOFF.md) 의 ADR 에,
앞으로 할 일은 [TASKS.md](TASKS.md) 에 있다.

## 적는 법

- 과제를 끝내면 맨 위 "최근" 에 한 줄 적는다: `날짜 · T-xx · 무엇 · 커밋` 과 **한 줄짜리 교훈**(있으면)
- 여러 커밋이 한 흐름이면 묶어서 적는다. 커밋 목록 전체는 `git log` 가 이미 갖고 있다 —
  여기는 **흐름과 숫자**를 남기는 곳이다
- 공개 사이트에 반영된 시점은 **공개본** 표시를 붙인다. 로컬 `dev` 에만 있는 것과 구분해야 한다
