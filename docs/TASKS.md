## 쓰는 법

1. 위에서부터 하나 고른다. 번호(`T-xx`)는 바뀌지 않는다 — 커밋 메시지와 이력에서 이 번호로 부른다.
2. **완료 조건**을 만족해야 끝난 것이다. 코드가 들어갔다고 끝이 아니다.
3. 끝나면 이 파일에서 [완료](#완료)로 옮기고(날짜·커밋), [HISTORY.md](HISTORY.md) 에 한 줄 적는다.
4. 하다가 새로 발견한 일은 **바로 여기 추가한다.** 머릿속이나 대화에만 두면 사라진다.

- **크기:** 2시간

## P1 — 이 도구가 맞는지

### T-20
- [ ] **출발지 이름을 치고 Enter 를 누르면 지도가 안 따라간다** — 공개 사이트에서 재현

09-15 공개본 확인 중 발견. `운정중앙` 을 타이핑하고 Enter 를 누르면 목록·헤드라인은
"동네 6곳"으로 바뀌는데 **지도는 서울 한가운데 그대로이고 출발지 마커도 강남에 남는다.**
목록을 클릭하거나 방향키로 고른 뒤 Enter 면 정상이다.

원인: 타이핑만 하면 콤보박스의 `activeIndex` 가 -1 이라 Enter 를 가로채지 않고
폼 기본 동작 `run()` 으로 넘긴다(`web/src/combobox.ts` Enter 분기). `run()` 은
`state.origin` 을 바꾸고 `render()` 만 부르지 **`showOrigins()` 를 안 불러서**
`fitted` 가 첫 화면의 `true` 로 남고, 마커도 카메라도 안 움직인다(`web/src/main.ts` `run`).

원래 있던 결함이다. 먼 역(GTX-A·서해선)이 생기면서 눈에 띄게 됐다 — 결과가 전부 화면 밖에 있다.

- **완료 조건:** 타이핑+Enter, 목록 클릭, 방향키+Enter, 지도에서 역 클릭, 공유 링크 — **다섯 경로 모두** 마커와 화면이 새 출발지로 간다
- **크기:** 30분

### T-04
- [ ] **카카오와 분포끼리 대보기** — 재현율 0.46 은 진짜인가

지금 대조는 **우리 중앙값**(슬롯 안 30개 출발 분)과 **카카오 한 번**("지금 나가면")을 댄다.
배차가 성기고 고르지 않을수록 이 둘은 원리적으로 벌어진다. 최선의 출발 분 기준 편향은
+1.0분인데 중앙값 기준은 +8.6분이다.

- **방법:** OD 표본 15개를 골라 퇴근 시간대에 카카오를 **6분 간격 5번** 묻는다(75회).
  같은 시각들로 우리 값도 뽑아 두 분포의 중앙값을 댄다. 브라우저 파이프라인은
  [ADR-37 도구](HANDOFF.md#adr-37-현실과-대봤다--정밀도-095-재현율-057-2026-09-09) 에 있다(스크린샷 없이 JS 한 줄)
- **완료 조건:** "중앙값끼리 대면 편향 ○분"을 숫자로 적은 ADR. 그 결과로 행렬이 쓰는 통계(중앙값인가 다른 분위수인가)를 유지할지 바꿀지 결정
- **이게 정하는 것:** T-08 이하 GTFS 작업을 할 가치가 있는가
- **크기:** 반나절 (수집은 17~20시에만 의미가 있다)

### T-06
- [ ] **회귀 테스트** — `builder/src/test/kotlin/reach/` 가 비어 있다

불변식 검사(`--mode invariants`)는 "스스로 모순되지 않는가"를 보고, 이미 고친 결함이
다시 들어오는 건 못 막는다. 이번에 잡은 결함은 **전부 조용히 틀리는 종류**였다.

최소 이 다섯 건을 테스트로 고정한다:

1. OSM 부역명 — `교대(법원·검찰청)` 와 `교대` 가 한 역으로 묶여 2↔3호선 환승이 있다
2. 열차코드 재사용 — 인접 정차가 1시간 넘게 벌어지면 다른 운행이다(유령 구간 금지)
3. 자정 넘김 — 23:50→00:30 열차의 정차 순서가 안 뒤집힌다
4. 한 방향 소실 — 서로 안 겹치는 두 토막(GTX-A)도 양방향이 남는다
5. 급행 선로 오염 — 급행 계통은 `trackEdges` 에 안 들어간다. `광역급행철도`는 급행이 아니다

- **완료 조건:** `./gradlew :builder:test` 에 위 다섯 건. 각 테스트가 **고치기 전 코드로 되돌리면 실패**하는 걸 한 번씩 확인
- **크기:** 하루

### T-10
- [ ] **한 방향으로만 서는 승강장 7개**

빌드할 때마다 `한 방향으로만 서는 승강장 12개` 가 찍힌다. 그중 5개는 6호선 응암순환이라

- **완료 조건:** 응암순환은 허용목록으로 빼서 경고에서 지우고, 나머지는 반대 방향을 채우거나 KRIC 시각표로 덮였는지 확인. 경고가 0 이 되거나 남은 것마다 이유가 적혀 있다
- **크기:** 2시간

### T-11
- [ ] **버스 시간대 배차 배율의 품질**

`data/bus-headway.json` 이 이제 19개 유형에서 배율을 낸다(스냅샷 64개). 그런데:

- `"1"`, `"14"` 같은 **숫자 유형**이 섞여 있다 — 경기 노선유형 코드가 이름으로 안 바뀌었다
- 배율이 `2.0` 까지 튄다(유형 `1`·`6`·`14`). 운행 대수의 **중앙값이 1~2대**인 유형은 1대 차이가 두 배가 된다

- **완료 조건:** 숫자 코드를 이름으로 매핑. 표본이 작은 칸은 1.0 으로 두거나 이웃 시간대와 평활. 적용 전후로 T-05 지표를 대본다
- **크기:** 반나절
